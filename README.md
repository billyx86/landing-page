# landing-page

A cat-themed landing page project (freeCodeCamp / The Odin Project style).
Static HTML + CSS, no JavaScript, no build step.

## Usage

Open `index.html` in a browser.

## Sections

- **Header** — logo placeholder + three nav links
- **Hero** — headline, subtext, sign-up button and hero image
- **Info** — four cat-fact boxes with images
- **Quote** — a pull quote ("Meow. — Cat")
- **Call to action** — closing sign-up prompt
- **Footer** — copyright

## Tests

A `node:test` suite validates the HTML (responsive viewport meta, alt text
on every image):

```sh
npm test
```
